## Introdução

Bem-vindo ao primeiro post deste blog! Este post explica a stack tecnológica e a arquitetura por trás deste sistema de blog.

## A Stack

Este blog é construído com:

- **Next.js 15** — App Router com React Server Components
- **MDX** — Markdown com componentes React integrados
- **Tailwind CSS 4** + **daisyUI 5** — Estilização
- **Cloudflare Workers** — Implantação na edge via OpenNext

## Destaque de Código

Aqui está um exemplo de código com destaque de sintaxe:

```typescript
import { compileMDX } from 'next-mdx-remote/rsc';

const { content, frontmatter } = await compileMDX<{ title: string }>({
  source: mdxString,
  options: { parseFrontmatter: true },
});
```

## Suporte Multilíngue

Os posts do blog suportam múltiplos idiomas. Cada post pode ter traduções em inglês, português e catalão. Se uma tradução não estiver disponível, a versão em inglês é exibida com um banner de aviso.
